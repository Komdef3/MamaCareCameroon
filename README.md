# MamaCareCameroon
A Maternal Care Web Platform

Overview:
Maternal health remains a critical challenge in Cameroon and across sub-Saharan Africa. Pregnant women often struggle to access timely medical advice, track symptoms effectively, and manage their prenatal appointments in one place. Many mothers lack digital tools that are both accessible and specifically designed for maternal care. MamaCare was developed to address this gap by providing a comprehensive, AI-powered web platform dedicated to maternal health management.
This project aims to design and develop a full-stack maternal care web application that enables pregnant women to track symptoms, manage prenatal appointments, interact with an AI health assistant, and gain data-driven health insights, all in one user-friendly platform.

Tools and Technology Stack:
- MamaCare was built using a modern full-stack architecture. 
- The frontend was developed using React.js with TanStack Router and Tailwind CSS, while the backend was built with FastAPI (Python).
- PostgreSQL was used as the database. 
- AI capabilities were integrated using the Groq API with the Llama 3.3 70B model. Data mining techniques were implemented using Python pandas and scikit-learn libraries to analyse symptom patterns and generate health insights. 
- DevOps tools including Git, GitHub, GitHub Actions CI/CD pipeline, Prometheus, and Grafana were used for version control, automated testing, and monitoring.
